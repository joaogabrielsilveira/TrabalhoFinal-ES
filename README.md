# TrabalhoFinal-ES
Trabalho final da disciplina de Engenharia de Software 2026/2

## Compilação e execução
Para rodar o programa, basta rodar ```java Build.java``` na pasta raiz do projeto.
Para apenas compilar e gerar os arquivos .class, use o comando ```java Build.java build```.
Para apagar os arquivos compilados, rode ```java Build.java clean```.

## Uso de Inteligência Artificial
A implementação inicial do projeto foi feita sem o uso de LLMs, mas foi feito seu uso posteriormente para a adição de funcionalidades, para o processo de Build e para a correção de bugs e vulnerabilidades.
